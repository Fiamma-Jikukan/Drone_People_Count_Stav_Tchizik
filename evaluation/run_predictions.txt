========================================================================
Evaluation predictions — ONE command runs all 8 evaluation images.
========================================================================
Run from the repo root with the .venv active (PyCharm terminal, or after
".venv\Scripts\activate"). Uses yolo11x weights (best recall, as decided).

The 8 evaluation images (4 pairs) live in evaluation/eval_images/, so a single
command processes them all with the model loaded only once.

NOTES
  * The command downloads yolo11x.pt (~110 MB) automatically on first use.
  * On CPU, expect a few minutes total: each RGB image ~30-60s with SAHI tiling;
    thermal is faster.
  * Modality (rgb/thermal) is inferred from the _V / _T file name.
  * Thresholds use the default operating point (rgb 0.25, thermal 0.20, NMS 0.5).
  * Outputs:
      evaluation/predictions/json/<name>.json        <- used for the metrics
      evaluation/predictions/annotated/<name>.jpg     <- visual check
------------------------------------------------------------------------

python main.py --input evaluation/eval_images --output evaluation/predictions --weights yolo11x.pt
